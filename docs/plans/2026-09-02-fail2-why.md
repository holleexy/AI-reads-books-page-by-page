## なぜ duplicates に入らないか

`collect_duplicates` の union-find は、自己辺でもノードは作るが、**メンバーが2未満のグループは捨てる**。

```214:214:book_semantica/quality.py
    return [sorted(set(members)) for members in buckets.values() if len(set(members)) > 1]
```

品質ゲート側は `frozenset({src, tgt})` をそのまま見る。src と tgt が同じだと `{'Product Owner'}` になり、2要素グループにも exact_id の `product owner`（小文字）にも含まれない。

抽出そのものは通っている。ゲートで落ちるので、蓄積グラフに自己 `same_as` が残るかぎり、再開しても同じエラーで落ちる。
