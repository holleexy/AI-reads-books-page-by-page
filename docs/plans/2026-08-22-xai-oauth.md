# xAI OAuth を読む経路に載せる

xAI は API キーだけでなく、Hermes が保存している SuperGrok / X Premium+ の OAuth でも呼べる。
このマシンでは `/opt/hermes-cli/.hermes/auth.json` の `xai-oauth` を Bearer にすると `https://api.x.ai/v1/chat/completions` が 200 になる。

## 認証の優先順

1. `XAI_API_KEY`（明示キー）
2. Hermes `auth.json` の xAI OAuth（期限切れなら refresh）
3. `CURSOR_API_KEY`（Cursor Agent SDK）
