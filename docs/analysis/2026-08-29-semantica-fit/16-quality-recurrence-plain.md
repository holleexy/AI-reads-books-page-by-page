# 同じすきまが戻らないようにした

日付は 2026-08-30 である。
対象読者は、プログラムの内部を追わない人である。
前の文書は、4 つのすきまが何だったかを書いた。
この文書は、同じすきまが次の書き出しで戻らないようにした、という話である。

## 直しただけでは足りない理由

一度きれいにしたファイルは、次に関係一覧を出したときに上書きされる。
書き出しの途中で、人に見せる名前の代わりに内部用の英語を使う、同じものを結ぶ印を重複として数えない、確からしさの数値差を食い違いとして残す、型の印を二重に付ける、のどれかがもう一度起きると、すきまは戻る。

前回の直しは「きれいな書き方を用意した」までだった。
書き出しが必ずそれを使う、とは限らなかった。

## いまの約束

関係一覧を出すとき、最後に必ず検査する。
検査に落ちたら、ファイルは完成扱いにしない。
途中で止める。

検査の内容は次である。

1. 種類の見出しが、日本語の見せる名前になっているか
2. 英語と日本語が「同じものを指す」と付いているのに、重複の一覧が空ではないか
3. 食い違いの一覧に、対象が空の行や確からしさだけの行が残っていないか
4. 型の印が二重になっていないか

すでに出した『労務入門』の一覧だけ直す「書き出しのやり直し」も、同じ検査を通る。

## 人がやること

普段は何もしなくてよい。
一覧を出したあと、途中で止まったら、すきまが戻ろうとしている。
止めずに出し切ったなら、4 つのすきまは今回は混ざっていない。
