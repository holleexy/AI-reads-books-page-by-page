# できることとできないことの対応表

凡例は次である。

- **済み**：このリポジトリが実装し、成果物がある
- **欠落**：このリポジトリには無く、Semantica を足すと届く
- **過剰**：Semantica にはあるが、本の学習には今いらない
- **両方なし**：どちらも本の学習に特化していない
