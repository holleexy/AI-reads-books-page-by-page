# Kindle キャプチャが途中で止まる件（2026-08-29）

本によっては自動めくりが途中で止まっていた。
原因は、画面が変わらないキャプチャが 3 回続いたら末尾とみなしていたことと、めくり手段が矢印と右端クリックだけだったことである。

Kindle for PC は本によって次が違う。

- 右キーで進む
- ページダウンやスペースで進む
- 本文をクリックしてからキーが効く
- ホイールでスクロールする
- 描画が遅く、めくり直後は前のページのまま撮れる

対策は次である。

1. 画面が変わるまで、フォーカスクリック、矢印、端クリック、PageDown、ホイール、PostMessage を順に試す
2. 連続キャプチャが一致するまで待ってから保存する
3. 変わらないページを新しい PNG として連番保存しない
4. 手段を一通り試しても変わらないときだけ、末尾とみなす
