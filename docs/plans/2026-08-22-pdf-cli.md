# PDF を引数で渡す

`read_books.py` はソース編集と Enter 待ちをやめる。
PDF のパスを渡せば、その冊を全書処理する。

## 使い方

```bash
./run.sh read_books.py /path/to/book.pdf
./run.sh read_books.py a.pdf b.pdf
./run.sh read_books.py kindle_pdfs/
./run.sh read_books.py book.pdf --pages 60
```

## 仕様

- 位置引数は PDF ファイル、または直下の `*.pdf` を読むディレクトリ
- 複数冊は同じクライアントで順に処理する
- 既定は全書（`test_pages=None`）。Enter 待ちはしない
- `--pages N` でページ上限
- `--interval N` で区間要約の間隔。既定 20。`0` で最終要約だけ
- ファイルが無い、PDF でない、ディレクトリが空なら非ゼロで終了する
